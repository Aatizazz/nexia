# Contributing to Nexia

Thanks for your interest in contributing! 🎉

## How to Contribute

### 1. Report Bugs
Found a bug? [Open an issue](https://github.com/aatizaz/nexia/issues) with:
- Clear description
- Steps to reproduce
- Expected vs actual behavior
- Python version & OS

### 2. Suggest Features
Have an idea? [Open a feature request](https://github.com/aatizaz/nexia/issues) with:
- Problem it solves
- Why it's important
- Example usage

### 3. Improve Documentation
- Fix typos
- Add examples
- Improve clarity
- Add diagrams

### 4. Submit Code

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly
5. Submit a pull request

## Development Setup

```bash
# Clone your fork
git clone https://github.com/YOUR-USERNAME/nexia.git
cd nexia

# Test the tools
python nexia-index.py --help
python nexia-memory.py --help

# Test with examples
python nexia-index.py --build --input ./examples/sample-docs
```

## Code Style

- Keep it simple and readable
- Add comments for complex logic
- Follow existing patterns
- Test before submitting

## Pull Request Process

1. Update README if needed
2. Add/update tests
3. Submit PR with clear description
4. Respond to feedback

## Code of Conduct

- Be respectful
- Be helpful
- Be constructive
- Assume good intentions
